# Closed vascular and coupled-substrate proof

`../../specs/knight_body.json` remains the sparse vascular source: skeleton
provenance, pump region, exchange territories, tissue demand, and carrier
scale. Nodes, edges, radii, terminal sites, physical fields, and exact
coordinates are solver-owned derived results.

The same body source uses optional non-uniform `gencyl.stations` for sparse
axial shape control. Stations place authored cross-sections; they do not
author mesh vertices or vessel geometry. Omitting them retains the historical
uniform interpolation exactly.

The canonical active scene now instantiates only this body and its held sword.
The armor subsystem and its reusable element sources remain available, but no
armor participates in the current receipt or render set. Body quality is the
active visual question.

The old `rehearsal/vascular/render_acceptance.py` execution surface has been
deleted. It could repaint a GLB without proving that the assembly had accepted
hydraulics, heat transport, or mechanics. The sole current renderer is
`../coupled/render_acceptance.py`, reached through the direct module CLI
`python -m rehearsal.coupled.render_cli`. It consumes an `AcceptedAssembly`,
derives scalar colours only from its accepted thermal and mechanics fields,
and publishes nothing when compilation or render preflight rejects.

## Current authoritative evidence

`knight_closed_vascular.receipt.txt` is the textual assembly receipt and
`knight_closed_vascular.glb` is its exchange scene. The current accepted run
reports:

- closed graph: 1,058 nodes, 1,312 edges, 256 exchange pairs, with positive
  solved flow on every supply, exchange, and return edge;
- one-way structural guidance: 2,435 provisional Q1 stress samples and a
  bounded CCO cost multiplier of `1.05`;
- physical coolant flow `2.077676e-6 m^3/s` at `2.5e5 Pa`, with maximum
  Reynolds number `2.187561e3` and relative balance error `4.107e-14`;
- maximum body temperature `305.1516 K`, maximum thermal gradient
  `54.95532 K/m`, solver residual `6.885e-16`, and relative energy imbalance
  `2.182e-15`;
- maximum displacement `9.967047e-5 m`, maximum von Mises stress
  `1.152641e7 Pa`, yield safety factor `14.74873`, buckling factor
  `1709.815`, and burst safety factor `14.79663`;
- one retained rigid-payload interface for the held sword, and refinement
  changes of `2.6398%` temperature utilization, `0.0383%` displacement
  utilization, and `2.2219%` yield utilization.

Those are measured receipts, not claims that every physical regime has been
resolved. The same receipt explicitly lists the remaining unevaluated
subgrid-channel global strength/stiffness and local equipment/contact fields.

## Commands

Compile the accepted exchange scene and textual receipt:

```sh
uv run --frozen python -m golem.assembly \
  rehearsal/reforge/knight_separated.json \
  --glb rehearsal/vascular/knight_closed_vascular.glb \
  > rehearsal/vascular/knight_closed_vascular.receipt.txt
```

Render directly from a fresh accepted compile result. The output directory is
intentionally required not to exist, so a rejected run cannot overwrite a
previous accepted image set:

```sh
uv run --frozen python -m rehearsal.coupled.render_cli \
  rehearsal/reforge/knight_separated.json \
  <fresh-output-directory> 720
```

Focused validation:

```sh
uv run --frozen pytest -q \
  tests/test_coupled_assembly.py tests/test_coupled_render.py
```

## Current D30 performance receipt

Fresh-process measurements on the acceptance machine report:

- service-free: three cold samples `11.7419475`, `12.0211231`, and
  `12.9781788 s` (mean `12.2470831 s`), warm median `0.000244917 s`, and
  `2,258,075,648` bytes peak RSS;
- coupled: `62.467986125 s` cold, warm median `0.000289709 s`, and
  `3,409,838,080` bytes peak RSS.

The coupled path improves all three D29 measurements. The service-free cold
path is 14.1% slower than D29 because D30 deliberately replaced the smaller
pipe body with a denser stationed profile; that cost is named rather than
hidden by lowering mesh or terminal resolution. Its warm wall time and peak
memory—the explicit 256-pair non-regression gate—both improve. Refinement no
longer solves a second buckling spectrum that the refinement receipt never
claims, while the authoritative base solve still proves buckling. Sparse Q1
assembly uses bounded 32-bit indices when lawful and shares a single stiffness
section across numerically uniform cells.

These D30 timing comparisons used the former armored specimen and remain
historical. D34 changed the canonical element set, so its next performance
baseline must be measured afresh rather than compared as if the workload were
unchanged.

## D29 performance baseline

Fresh-process content-addressed compiles on the acceptance machine measured:

- service-free: `10.735286750 s` cold, `0.000521750 s` unchanged warm,
  `2,710,978,560` bytes peak RSS;
- coupled: `68.080369625 s` cold, `0.000597250 s` unchanged warm,
  `3,584,491,520` bytes peak RSS.

Both warm calls returned the same immutable object and receipt. The
service-free path beats the D27 `11.973 s` non-regression baseline. The
coupled path owns its own measured budget because it performs provisional and
final mechanics, thermal sizing, hydraulics, heat transport, interface
gluing, and refinement; no terminal pairs or physics resolution were removed.
