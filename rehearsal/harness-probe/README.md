# Harness probe — the conduit instrument, user-tested by fresh daimones

**Honest header: two fenced probes, n=2, same model family (opus), same evening the harness was written (2026-07-18). Operators received ONLY HELP.txt and a brief; no source, no plans, no records. Unblinded coordinator (fable) wrote both the tool and this summary. Signal for the lesson register, not evidence of usability.**

## Setup

Subject: `acolyte.json` (plain hooded figure, no decoration). Tool: `golem/conduits/harness.py` — the declare→grow→receipt→adjust loop with render-on-demand, driven via `--script` (the ops file is the session; rerun replays deterministically). Budgets: ≤8 grows, ≤2 renders. Probe A ("ornamentalist"): surface conduits only. Probe B ("fleshcrafter"): vascular + reinforcement + a grown mirrored crown from authored intent volumes.

## Results

Both completed their briefs with clean final receipts and legible renders; both scored the tool **3/5** with non-overlapping friction lists (`probe_a/REPORT.md`, `probe_b/REPORT.md`, final elements and sheets alongside).

## Lesson-register candidates (the harvest)

1. **Receipts must cover every emission.** Grooves print nothing (A) and appendages print nothing (B) — both operators had to spend budgeted renders to confirm cheap operations, breaking the tool's own "grow is cheap, render to confirm" promise. B's first crown grew *nothing* and was silently absent. Fix: per-declaration receipt lines for all emissions (groove affected-vertex counts; appendage parts/nodes/edges/bbox).
2. **Face count is not visibility** (A): a healthy band hidden behind clasped hands read as success in the receipt and was invisible in renders. The receipt has no occlusion/visibility sense — the harness-level echo of the plan's missing appeal signal (§10.4/D7).
3. **Orientation must be queryable** (A): `parts` without positions forced a full `show` dump to learn which end of the robe is t=0. This is the SAME lesson the v0.4 session probe registered (`outline geometry`) — twice independently reached-for; it is load-bearing.
4. **A raw exception escaped the rejection discipline** (B): `min() arg is an empty sequence` from a reinforce parameter combination — unactionable, violating "rejections are answers." The typed-obstruction net has a hole.
5. **Auto-res breaks receipt comparability** (B): bounds-coupled resolution shifts retessellate everything, so face counts cannot be diffed across grows to detect what a change added. A pinned-res mode (or per-declaration deltas) is needed.
6. Smaller reaches: appendage `count` semantics undocumented; t-range/offset on face_line; scoped `show <id>`; material swatches; grow-time variance warnings.

## What shone

The loop itself: fast, safe, honest about the solid; the integrity verdict line; vascular reinforcement's receipt numbers mapping intuitively to rendered swells (B: "coverage/max mapped to convincing swells"). The instrument works; its senses are incomplete in exactly the ways fresh operators could find and we could not.
