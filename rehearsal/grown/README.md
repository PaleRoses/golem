# Grown guardian — archived regime-mismatch evidence

**Historical artifact, rejected as creature architecture.** This directory
preserves the D20 experiment in which a seeded space-colonization tree was
enveloped into an articulated guardian. The result was judged poor and D21
identified the cause: stochastic branching is suitable for appendages such as
antlers, roots, venation, tendrils, and coral, not for a creature's authored
skeleton or for detailed circulation.

The GLB, graph, and sheets remain only as the visual receipt behind that
decision. Their obsolete executable demo was deleted. They are not inputs to
the live GOLEM pipeline and must not be described as vasculature, structural
proof, or a supported body-generation API.

Live ownership is now unambiguous:

- `golem/kernel/body.py` owns authored creature skeleton and morphology;
- `golem/conduits/appendage.py` owns seeded appendage growth;
- `golem/kernel/anatomy.py` owns seedless closed vascular realization from
  sparse `anatomy/0.1` intent.
